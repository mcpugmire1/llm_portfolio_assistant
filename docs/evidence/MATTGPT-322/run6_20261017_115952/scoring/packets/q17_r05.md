## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would help engineers earn certifications and apply cloud-native technologies on projects.

As Cloud Native Architecture Lead, Matt led AWS Launchpad from July 2018 to November 2019, working in collaboration with AWS to develop a tailored enablement program. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Rather than relying on theory alone, Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. He established cloud expert mentorship teams so participants could learn best practices from experienced practitioners. Group coaching sessions and knowledge-sharing workshops gave engineers additional opportunities to work through questions and learn together.

The program combined a defined learning path, practical application, and ongoing mentorship. Its scope extended across Accenture, with engineers preparing for AWS Solutions Architect and DevOps Engineer certifications while building the cloud competencies needed for transformation projects.

More than 200 professionals earned AWS certifications through the program. AWS Launchpad accelerated cloud adoption and the launch of cloud-native initiatives, while the mentorship teams and knowledge-sharing workshops supported continued learning beyond certification.
