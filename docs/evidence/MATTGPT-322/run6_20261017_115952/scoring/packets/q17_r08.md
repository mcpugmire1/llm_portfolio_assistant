## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led AWS Launchpad at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to prepare engineers for cloud-native transformation work, not just certification exams.

Matt developed the program in collaboration with AWS, combining structured learning paths, hands-on labs, and mentor-based training. The learning paths covered AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Instead of relying on theory alone, he delivered interactive workshops and labs that immersed engineers in real-world AWS environments. Engineers could apply what they were learning while preparing for certifications, including AWS Solutions Architect and DevOps Engineer.

He also established cloud expert mentorship teams to reinforce best practices and retain knowledge within Accenture. Group coaching sessions and knowledge-sharing workshops gave participants opportunities to learn together, ask questions, and work with experienced practitioners. Those practices made mentorship and practical application part of the program rather than leaving engineers to study independently.

More than 200 professionals earned AWS certifications through Launchpad. The program accelerated cloud adoption and the launch of cloud-native initiatives, with structured learning, practical AWS work, and ongoing mentorship built into the same program.
