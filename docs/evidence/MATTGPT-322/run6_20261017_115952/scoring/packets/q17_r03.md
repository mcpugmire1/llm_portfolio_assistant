## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to build practical cloud skills, not just prepare people to pass exams.

Matt worked with AWS to develop a tailored enablement program. He designed structured learning paths and certification programs covering cloud-native application development and services including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. Instead of relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments.

He brought cloud experts and engineers together through mentorship teams, group coaching sessions, and knowledge-sharing workshops. The mentorship teams embedded AWS best practices and institutional knowledge, giving participants support beyond individual training sessions. The learning paths provided structure, while the labs gave engineers opportunities to apply what they were learning.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives across Accenture.

Matt also coordinated a separate AWS training effort for Accenture’s ARISE HBCU Conference from 2020 through 2023. For that program, he assembled presenters, developed curriculum, secured keynote speakers, personally delivered cloud computing and AWS fundamentals sessions, and coordinated free AWS certificate training opportunities. More than 250 students and recent graduates participated each year. That figure measures participation, not certifications earned.

### B

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would prepare engineers for cloud-native projects, not just certification exams.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS from July 2018 to November 2019. He designed structured learning paths covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Instead of relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. The learning paths connected certification preparation with practical application, so engineers worked with the technologies they would use on cloud transformation projects.

Matt also established cloud expert mentorship teams to share best practices and build institutional knowledge. He organized group coaching sessions and knowledge-sharing workshops, giving participants support beyond individual study. The program combined structured coursework, practical exercises, and access to experienced cloud practitioners rather than treating certification as a standalone training event.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer. The program accelerated cloud adoption across Accenture and the launch of cloud-native initiatives, while establishing ongoing mentorship and knowledge sharing across teams.
