## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured cloud enablement program that prepared engineers for cloud-native application development, not just certification exams.

Matt led AWS Launchpad in collaboration with AWS from July 2018 to November 2019. He built the program around structured learning paths, hands-on labs, and mentor-based training. The learning paths covered AWS core services and cloud-native technologies, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate.

Instead of relying on theory alone, Matt delivered interactive workshops and labs that immersed engineers in real-world AWS environments. Those sessions gave participants practical application alongside their certification preparation. The certification programs included AWS Solutions Architect and DevOps Engineer.

He also established cloud expert mentorship teams so engineers could learn AWS best practices from experienced practitioners. Group coaching sessions and knowledge-sharing workshops added opportunities for participants to work through questions together and share what they were learning. The program combined a defined learning path with practical exercises, expert guidance, and peer learning rather than treating certification as an isolated study task.

More than 200 professionals earned AWS certifications through the program. AWS Launchpad accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, while establishing ongoing mentorship and knowledge-sharing practices beyond the certification exams.
