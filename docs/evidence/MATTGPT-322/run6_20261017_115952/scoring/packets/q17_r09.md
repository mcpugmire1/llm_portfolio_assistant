## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The studio needed a structured cloud enablement program that would prepare engineers for cloud-native transformation initiatives, internally and with clients.

Matt led AWS Launchpad at the Atlanta Innovation Hub, developed in collaboration with AWS. From July 2018 to November 2019, the program combined structured learning paths, hands-on labs, and mentor-based training rather than relying on theory alone.

He designed learning paths and certification programs around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Interactive workshops and labs immersed engineers in real-world AWS environments so they could reinforce what they learned through practical application.

Matt also established cloud expert mentorship teams to embed AWS best practices and retain institutional knowledge. He organized group coaching sessions and knowledge-sharing workshops, giving engineers support beyond the individual coursework. Certification preparation sat alongside practical cloud development and ongoing coaching, rather than operating as a standalone exam-preparation effort.

Through AWS Launchpad, more than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated AWS adoption and the launch of cloud-native initiatives across Accenture.

Separately, Matt built NEW IT SKILLS NOW with subject-matter experts, using modular, self-paced learning paths, challenging hands-on labs, a program website, a progress tracker, and weekly office hours. That program trained 300+ professionals across AWS and other technologies; that figure is a training count, not Launchpad’s certification count.
