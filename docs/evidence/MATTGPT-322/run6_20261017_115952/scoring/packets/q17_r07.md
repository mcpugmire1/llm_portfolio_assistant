## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured cloud enablement program that prepared engineers for cloud-native work, not just certification exams.

Matt led AWS Launchpad in collaboration with AWS, combining structured learning paths, hands-on labs, and mentor-based training. The program ran from July 2018 through November 2019.

He designed learning paths and certification programs around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Rather than relying on theory alone, he delivered interactive workshops and labs that immersed engineers in real-world AWS environments, reinforcing practical application.

Matt also established cloud expert mentorship teams to embed AWS best practices and build institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants opportunities to learn together, with support extending beyond the individual training sessions. The program paired certification preparation with practical work and access to experienced cloud practitioners.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, while establishing ongoing mentorship and knowledge-sharing practices for continued learning.

He organized group coaching sessions and knowledge-sharing workshops, giving participants support beyond the formal training.
