## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it! Matt led AWS Launchpad at Accenture’s Atlanta Innovation Hub, building the program around hands-on labs, structured learning paths, and mentor-based training.

Traditional training at Accenture’s Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to help people earn certifications while also preparing them to apply AWS services to cloud-native application development.

Matt led Launchpad in collaboration with AWS. He designed structured learning paths and certification programs covering core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. Rather than relying on theory, he delivered interactive workshops and labs that immersed engineers in real-world AWS environments, giving them practical application alongside their certification preparation.

He also established cloud expert mentorship teams so engineers had people to turn to as they learned. Group coaching sessions and knowledge-sharing workshops gave participants opportunities to work through questions together, while mentors reinforced AWS best practices and built institutional knowledge. Learning was supported by experts and peers, rather than left entirely to individual study.

The program supported 200+ professionals in earning AWS certifications, including Solutions Architect and DevOps Engineer certifications. Engineers gained cloud skills they could use to lead cloud transformation projects, and Accenture accelerated AWS adoption and the launch of cloud-native initiatives.

Matt also established cloud expert mentorship teams to embed best practices and build institutional knowledge. He organized group coaching sessions and knowledge-sharing workshops, giving engineers support beyond the individual coursework. Certification preparation was paired with practical work and access to cloud experts, rather than treated as a standalone exam exercise.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives across Accenture.

Separately, Matt built NEW IT SKILLS NOW, a broader self-paced learning program with modular learning paths, challenging hands-on labs, a program website, a progress tracker, and weekly office hours. That program trained 300+ professionals across AWS and other modern technologies and became the standard self-paced learning path across CloudFirst.
