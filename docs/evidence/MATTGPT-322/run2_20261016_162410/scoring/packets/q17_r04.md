## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that helped engineers earn certifications and apply what they learned to cloud-native application development.

Matt led AWS Launchpad in collaboration with AWS, moving beyond theory through interactive workshops, hands-on labs, and mentor-based training. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate.

The labs immersed engineers in real-world AWS environments so they could practice applying the technologies rather than only studying them. Matt also established cloud expert mentorship teams to embed best practices and retain institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants opportunities to learn together, with support from cloud experts alongside the structured learning paths.

The program ran from July 2018 to November 2019. More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. Engineers gained practical cloud experience alongside their credentials, equipping them to lead cloud transformation projects. The program accelerated cloud adoption at Accenture and established ongoing mentorship and knowledge-sharing practices to support continued learning beyond certification.
