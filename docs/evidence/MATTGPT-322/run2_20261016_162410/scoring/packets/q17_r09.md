## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would help engineers earn certifications and prepare them to lead cloud-native transformation initiatives.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS from July 2018 to November 2019. Rather than relying on theory alone, he built the program around structured learning paths, hands-on labs, and mentor-based training.

He designed learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Interactive workshops and labs immersed engineers in real-world AWS environments so they could reinforce what they learned through practical application.

Matt also established cloud expert mentorship teams. Engineers had access to experienced practitioners, group coaching sessions, and knowledge-sharing workshops, rather than having to work through the material on their own. Those sessions supported certification preparation while embedding AWS best practices and retaining knowledge across teams.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives. Engineers gained both certification credentials and practical experience with the services they would use on cloud transformation projects.
