## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured cloud enablement program that would prepare engineers for cloud-native transformation projects, not just certification exams.

As Cloud Native Architecture Lead, Matt led AWS Launchpad from July 2018 to November 2019, working in collaboration with AWS to develop a tailored program. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Instead of relying on theory, Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Practical application was part of the learning path, rather than something engineers had to figure out after completing training.

He also established cloud expert mentorship teams to embed AWS best practices and retain institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants ways to learn from experienced practitioners and from each other. The program combined structured study, practical work, and mentor-based training rather than treating certification preparation as an isolated activity.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer. AWS Launchpad accelerated adoption and the launch of cloud-native initiatives at Accenture, while establishing ongoing mentorship and knowledge-sharing practices for continued cloud learning.
