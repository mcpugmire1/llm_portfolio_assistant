## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that helped engineers earn certifications and apply cloud-native practices on projects.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Rather than relying on theory alone, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. The training connected certification preparation with practical application, so engineers could work with the technologies they were learning rather than only study them for an exam.

Matt also established cloud expert mentorship teams to embed best practices and share institutional knowledge. He organized group coaching sessions and knowledge-sharing workshops, giving participants access to experienced practitioners and opportunities to learn together. Structured learning paths, labs, mentorship, and coaching formed the program, rather than leaving engineers to prepare independently.

Over 200 professionals earned AWS certifications, including Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives, while giving engineers practical AWS experience and continued access to mentorship and shared learning.
