## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The studio needed a structured enablement program to upskill engineers and prepare teams for cloud-native application development, rather than relying on training that wasn’t keeping up.

From July 2018 to November 2019, Matt led AWS Launchpad in the Atlanta Innovation Hub, working in collaboration with AWS. He designed structured learning paths and certification programs around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. The goal was to build deep cloud competencies alongside certification preparation.

Instead of centering the program on theory, Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Participants practiced cloud-native application development and AWS best practices as part of their learning.

He also established cloud expert mentorship teams so engineers could learn from experienced practitioners. Group coaching sessions and knowledge-sharing workshops complemented the structured learning paths, giving participants ongoing support and opportunities to share knowledge. The program combined hands-on practice, mentor-based training, and certification preparation rather than treating the exam as a standalone activity.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption across Accenture and supported the launch of cloud-native initiatives.
