## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to help engineers earn certifications and prepare them to lead cloud-native transformation initiatives.

Matt developed Launchpad in collaboration with AWS. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Rather than relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments.

He also established cloud expert mentorship teams so participants could learn AWS best practices from experienced practitioners. Group coaching sessions and knowledge-sharing workshops gave engineers opportunities to work through the material together. The program combined structured learning, practical application, and mentor-based training rather than treating certification as an isolated exam-preparation exercise.

More than 200 professionals earned AWS certifications, including Solutions Architect and DevOps Engineer certifications. Engineers gained practical cloud experience alongside their credentials, and the program accelerated cloud adoption and the launch of cloud-native initiatives across Accenture. The mentorship teams and knowledge-sharing workshops also supported ongoing learning beyond the certification itself.
