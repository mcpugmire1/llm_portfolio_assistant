## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led AWS Launchpad at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to build practical cloud skills across Accenture, not just prepare people to pass an exam.

Matt developed the program in collaboration with AWS. He designed structured learning paths and certification programs around AWS core services and cloud-native application development. The curriculum included Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate.

Instead of relying on theory alone, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Engineers could apply the services they were learning rather than only study them. He also established cloud expert mentorship teams to embed best practices and retain institutional knowledge beyond individual training sessions.

Group coaching sessions and knowledge-sharing workshops gave participants additional support as they worked toward certifications, including AWS Solutions Architect and DevOps Engineer. The program combined structured study, practical application, and access to experienced cloud practitioners.

More than 200 professionals earned AWS certifications through Launchpad. The program accelerated cloud adoption and the launch of cloud-native initiatives.

Separately, Matt built NEW IT SKILLS NOW with subject-matter experts: modular, self-paced learning paths, challenging hands-on labs, a program website, a progress tracker, and weekly office hours. That broader program trained 300+ professionals across AWS and other modern engineering technologies and became the standard self-paced learning path across CloudFirst.
