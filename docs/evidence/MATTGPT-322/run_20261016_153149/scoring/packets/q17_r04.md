## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would help engineers earn certifications and prepare them to lead cloud-native transformation initiatives.

As Cloud Native Architecture Lead, Matt led AWS Launchpad from July 2018 to November 2019. The program was developed in collaboration with AWS, with structured learning paths and certification programs covering core services including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Rather than relying on theory alone, Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Practical application was central to the training: engineers worked with the technologies covered by the learning paths, rather than treating certification preparation as a separate classroom exercise.

He also established cloud expert mentorship teams to embed AWS best practices and retain institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants additional opportunities to learn together, supported by experts rather than left to work through certification material alone.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated AWS adoption across Accenture and supported the launch of cloud-native initiatives. Its scope extended beyond exam preparation: structured learning paths, practical labs, expert mentorship, and group coaching were all part of the program.
