## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The AWS Launchpad program was intended to address those gaps through structured cloud enablement, with practical application rather than theory alone.

Matt led Launchpad at the Atlanta Innovation Hub from July 2018 to November 2019, working in collaboration with AWS. The goal was to certify engineers, build deep cloud competencies, and prepare teams to lead cloud-native transformation initiatives.

He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Rather than relying on traditional training alone, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments.

Matt also established cloud expert mentorship teams so engineers could learn AWS best practices from experienced practitioners. He organized group coaching sessions and knowledge-sharing workshops, making mentorship and peer learning part of the program alongside the certification preparation.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture. Its learning paths, labs, mentorship teams, and group coaching supported ongoing cloud competency development beyond certification preparation.

### D

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would help engineers earn certifications and prepare them to lead cloud-native transformation initiatives.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS. Rather than relying on theory alone, he designed structured learning paths and certification programs paired with interactive workshops and hands-on labs. Engineers worked in real-world AWS environments, covering core services including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

He also established cloud expert mentorship teams so participants could learn from experienced practitioners. Group coaching sessions and knowledge-sharing workshops gave engineers ongoing support and opportunities to learn together. The program combined a defined learning path, practical application, and mentor-based training rather than treating certification preparation as an isolated study exercise.

The result was more than 200 professionals earning AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. Those professionals were equipped to lead cloud transformation projects, and the program accelerated AWS adoption across Accenture.

Separately, Matt built NEW IT SKILLS NOW, a broader self-paced program with modular learning paths, hands-on labs, a progress tracker, and weekly office hours. That program trained 300+ professionals across AWS and other modern engineering technologies. Its training total is separate from Launchpad’s certification results.
