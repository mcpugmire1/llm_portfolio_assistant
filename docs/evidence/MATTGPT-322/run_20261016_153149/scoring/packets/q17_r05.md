## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that helped engineers earn certifications and apply cloud-native technologies on projects, rather than rely on theory alone.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS from July 2018 through November 2019. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

The program put practical application at the center. Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Engineers could work with the technologies they were learning, rather than stop at course material or exam preparation.

He also established cloud expert mentorship teams so participants had experienced practitioners to learn from. Group coaching sessions and knowledge-sharing workshops gave engineers opportunities to ask questions, exchange knowledge, and continue developing their cloud competencies. The structure combined a defined learning path with hands-on practice and mentor-based training.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated AWS adoption and the launch of cloud-native initiatives at Accenture, while giving engineers practical training and ongoing access to cloud experts.
