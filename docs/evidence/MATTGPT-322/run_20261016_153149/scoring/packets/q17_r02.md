## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would help engineers earn certifications while preparing them to work on cloud-native initiatives.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS from July 2018 through November 2019. Rather than relying on theory alone, he combined structured learning paths, hands-on labs, and mentor-based training.

He designed learning paths and certification programs covering AWS core services and cloud-native application development. The curriculum included Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. Interactive workshops and labs immersed engineers in real-world AWS environments, reinforcing practical application rather than just preparation for an exam.

Matt also established cloud expert mentorship teams so engineers could learn AWS best practices from experienced practitioners. He organized group coaching sessions and knowledge-sharing workshops, giving participants support beyond the individual learning paths. The program paired certification preparation with practical work and ongoing access to mentors, rather than treating training as a standalone course.

More than 200 professionals earned AWS certifications, including Solutions Architect and DevOps Engineer certifications. AWS Launchpad accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, with engineers using the training to prepare for cloud transformation projects.
