## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to build practical cloud skills, not just prepare people to pass certification exams.

Matt developed the program in collaboration with AWS. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Instead of relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Those sessions gave participants opportunities to apply the services they were studying.

He also brought cloud experts and engineers together through mentorship teams, group coaching sessions, and knowledge-sharing workshops. The cloud expert mentorship teams embedded AWS best practices and institutional knowledge into the program. Engineers had structured learning paths, practical exercises, and people they could learn from, rather than certification preparation alone.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated AWS adoption and the launch of cloud-native initiatives across Accenture, while establishing ongoing mentorship and knowledge-sharing practices for teams.
