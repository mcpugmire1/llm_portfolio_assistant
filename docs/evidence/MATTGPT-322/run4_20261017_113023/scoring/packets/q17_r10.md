## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to build practical cloud skills across Accenture, not just prepare people for an exam.

Working in collaboration with AWS, Matt designed structured learning paths and certification programs covering cloud-native application development and services including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. Instead of relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments.

He also established cloud expert mentorship teams so participants could learn AWS best practices from experienced practitioners. Group coaching sessions and knowledge-sharing workshops complemented the structured learning paths. Engineers had both a defined route toward certification and ongoing support as they developed practical skills.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives.

Matt also built related learning programs with distinct scopes. His NEW IT SKILLS NOW program used modular, self-paced paths, challenging hands-on labs, a program website, a progress tracker, and weekly office hours. It trained 300+ professionals across AWS and other modern technologies. Separately, for Accenture’s ARISE HBCU Conference, he coordinated AWS curriculum, presenters, keynote speakers, and free AWS certificate training opportunities. More than 250 students and recent graduates participated each year from 2020 through 2023.

The scope was broader than exam preparation: Matt was tasked with building deep cloud competencies across Accenture, certifying engineers, and preparing teams to lead cloud-native transformation initiatives. The combination of structured study, practical environments, expert mentorship, and group coaching supported that work.
