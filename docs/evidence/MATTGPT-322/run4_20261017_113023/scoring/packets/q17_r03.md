## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The AWS Launchpad program was developed in partnership with AWS to address those gaps through tailored enablement rather than theory alone.

Matt led Launchpad at the Atlanta Innovation Hub from July 2018 to November 2019. His task was to build deep cloud competencies across Accenture, certify engineers, and prepare teams to lead cloud-native transformation initiatives.

He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. The curriculum combined certification preparation with interactive workshops and hands-on labs, immersing engineers in real-world AWS environments to reinforce practical application over theory.

Matt also established cloud expert mentorship teams so engineers could learn AWS best practices from experienced practitioners. He organized group coaching sessions and knowledge-sharing workshops, making mentorship and peer learning part of the program rather than leaving participants to work through certification material independently. Those practices supported ongoing competency growth beyond the initial training.

Through Launchpad, more than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, with structured learning paths, practical labs, and expert mentorship supporting engineers as they prepared for cloud transformation projects.

### B

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would prepare engineers for cloud-native projects, not just certification exams.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS from July 2018 to November 2019. He designed structured learning paths covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Instead of relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. The learning paths connected certification preparation with practical application, so engineers worked with the technologies they would use on cloud transformation projects.

Matt also established cloud expert mentorship teams to share best practices and build institutional knowledge. He organized group coaching sessions and knowledge-sharing workshops, giving participants support beyond individual study. The program combined structured coursework, practical exercises, and access to experienced cloud practitioners rather than treating certification as a standalone training event.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer. The program accelerated cloud adoption across Accenture and the launch of cloud-native initiatives, while establishing ongoing mentorship and knowledge sharing across teams.
