## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Gaps in cloud competency were slowing adoption, while engineers needed practical experience to lead cloud-native initiatives. Matt led AWS Launchpad at the Atlanta Innovation Hub from July 2018 to November 2019, working with AWS to create a tailored enablement program.

He built the program around structured learning paths, hands-on labs, and mentor-based training rather than theory alone. The learning paths covered AWS core services and cloud-native application development, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. Certification preparation included AWS Solutions Architect and DevOps Engineer.

Matt delivered interactive workshops and labs that immersed engineers in real-world AWS environments. These sessions gave participants opportunities to apply what they were learning, rather than only study the services. He also established cloud expert mentorship teams to embed AWS best practices and build institutional knowledge beyond individual training sessions.

Group coaching sessions and knowledge-sharing workshops added ongoing support. Engineers could learn together, work with cloud experts, and continue developing their cloud competencies as technologies changed. The program’s scope was to build deep cloud competencies across Accenture, not just prepare a single project team for an exam.

More than 200 professionals earned AWS certifications through the program. The program accelerated cloud adoption and the launch of cloud-native initiatives, with structured learning, practical application, and mentorship supporting continued capability-building across teams.
