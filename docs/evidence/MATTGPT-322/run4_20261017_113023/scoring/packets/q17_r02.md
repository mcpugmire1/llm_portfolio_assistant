## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to help them earn certifications and apply those skills to cloud-native projects.

Matt worked with AWS to develop a tailored enablement program. He designed structured learning paths covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Rather than relying on theory alone, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments.

He also established cloud expert mentorship teams so engineers had experienced practitioners to learn from as they developed their skills. Group coaching sessions and knowledge-sharing workshops complemented the structured learning paths. Engineers could practice in labs, learn from mentors, and work through questions together, rather than depend only on traditional training. The mentorship teams also helped retain institutional knowledge and support ongoing learning beyond certification.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, with participants equipped to lead cloud transformation projects.

### B

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would prepare engineers for cloud-native transformation projects, not just certification exams.

Matt led AWS Launchpad in collaboration with AWS. He designed structured learning paths and certification programs around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Instead of relying on theory, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Engineers could apply what they were learning rather than only study the concepts. He established cloud expert mentorship teams to embed AWS best practices and retain institutional knowledge, then organized group coaching sessions and knowledge-sharing workshops to support continued learning.

The program combined structured certification preparation with practical application and access to experienced cloud practitioners. Matt supported professionals pursuing AWS Solutions Architect and DevOps Engineer certifications while preparing teams to lead cloud transformation projects.

More than 200 professionals earned AWS certifications through the program. AWS Launchpad accelerated cloud adoption and the launch of cloud-native initiatives at Accenture.

Separately, Matt built NEW IT SKILLS NOW, a broader self-paced program with modular learning paths, challenging hands-on labs, a program website, a progress tracker, and weekly office hours. That program trained 300+ professionals across AWS and other modern engineering technologies and became the standard self-paced learning path across CloudFirst.
