## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training programs at Liquid Studio couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to build practical cloud skills as well as prepare engineers for certification.

Matt led Launchpad in collaboration with AWS, designing structured learning paths around AWS core services and cloud-native application development. The curriculum included Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, with certification programs covering AWS Solutions Architect and DevOps Engineer.

Rather than relying on theory alone, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Practical application was part of the learning process, not something deferred until engineers joined a client project. The learning paths connected certification preparation with the technologies teams would use for cloud-native development.

He also established cloud expert mentorship teams to embed best practices and retain institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave engineers opportunities to learn together, supported by mentors rather than working through certification material entirely on their own.

More than 200 professionals earned AWS certifications through the program. The reported outcomes included accelerated cloud adoption and the launch of cloud-native initiatives, with mentorship and knowledge-sharing continuing beyond certification preparation.

### B

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The AWS Launchpad program was designed to build deep cloud competencies, certify engineers, and prepare teams to lead cloud-native transformation initiatives.

Matt led Launchpad at the Atlanta Innovation Hub from July 2018 to November 2019, in collaboration with AWS. Rather than relying on theory alone, he combined structured learning paths with interactive workshops, hands-on labs, and mentor-based training.

He designed the learning paths around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. The workshops immersed engineers in real-world AWS environments so they could reinforce what they learned through practical application.

Matt also established cloud expert mentorship teams to embed best practices and retain institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants continuing support beyond the training material. Certification preparation sat within that broader program of practical work, coaching, and shared learning, rather than being the only activity.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture.

Separately, Matt built NEW IT SKILLS NOW with subject-matter experts, using modular, self-paced learning paths, challenging hands-on labs, a program website, a progress tracker, and weekly office hours. That program trained 300+ professionals across AWS and other technologies; that figure is a training count, not Launchpad’s certification count.
