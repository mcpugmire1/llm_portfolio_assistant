## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would prepare engineers for cloud-native application development, not just certification exams.

Matt led AWS Launchpad as Cloud Native Architecture Lead from July 2018 to November 2019. Developed in collaboration with AWS, the program combined structured learning paths, hands-on labs, and mentor-based training.

He designed learning paths around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Rather than relying on theory alone, he delivered interactive workshops and labs that immersed engineers in real-world AWS environments so they could apply what they were learning.

Matt also established cloud expert mentorship teams to embed best practices and retain institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants opportunities to learn together, with mentorship supporting competency growth beyond the formal training.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture. The certification total belonged to AWS Launchpad itself, with practical labs, structured learning paths, and expert mentorship forming the program Matt led.

### B

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would prepare engineers for certifications and for cloud-native application development, rather than relying on theory alone.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS. He designed structured learning paths and certification programs covering core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. The program paired that curriculum with interactive workshops and hands-on labs, immersing engineers in real-world AWS environments so they could apply what they were learning.

Matt also established cloud expert mentorship teams. Engineers had access to mentors who reinforced AWS best practices and shared knowledge across teams. He organized group coaching sessions and knowledge-sharing workshops alongside the structured learning paths. The program combined practical exercises, expert support, and peer learning rather than treating certification preparation as an individual study exercise.

The program supported more than 200 professionals in earning AWS certifications, including AWS Solutions Architect and DevOps Engineer. Beyond the certification count, the engagement reported accelerated cloud adoption and launch of cloud-native initiatives at Accenture. The mentorship teams and knowledge-sharing workshops also supported ongoing learning beyond the certification preparation itself.
