## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured cloud enablement program that would prepare engineers for cloud-native application development, not just certification exams.

Matt led AWS Launchpad in collaboration with AWS from July 2018 to November 2019. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate. The program combined those learning paths with interactive workshops and hands-on labs in real-world AWS environments, reinforcing practical application over theory.

He also established cloud expert mentorship teams so engineers had support beyond the training sessions. Those mentors embedded AWS best practices and helped build institutional knowledge. Group coaching sessions and knowledge-sharing workshops gave participants opportunities to learn together, rather than relying only on individual study. The combination was structured learning, practical application, and mentor-based training, with certification connected to the work engineers would perform on cloud transformation projects.

More than 200 professionals earned AWS certifications, including Solutions Architect and DevOps Engineer certifications. The program accelerated AWS adoption and the launch of cloud-native initiatives across Accenture, while establishing mentorship and knowledge-sharing practices for ongoing learning.
