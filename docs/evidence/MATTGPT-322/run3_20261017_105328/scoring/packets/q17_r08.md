## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that helped engineers earn certifications and apply those skills to cloud-native projects.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS. Rather than relying on theory alone, he designed structured learning paths and certification programs around AWS core services and cloud-native application development. The curriculum covered Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, among other technologies.

He delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Those labs reinforced practical application alongside certification preparation, giving participants experience with the services they would use on cloud transformation projects.

Matt also established cloud expert mentorship teams so engineers had access to guidance and shared institutional knowledge. He organized group coaching sessions and knowledge-sharing workshops, making the program more than a set of individual study assignments. Engineers could learn from cloud experts and from one another, with support extending beyond the formal training.

The program ran from July 2018 to November 2019. More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption at Accenture and equipped participants to lead cloud transformation projects, while mentorship and knowledge-sharing supported continued learning after certification.
