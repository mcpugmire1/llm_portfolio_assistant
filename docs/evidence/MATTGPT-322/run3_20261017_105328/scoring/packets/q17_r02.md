## Visitor: How did Matt build the AWS certification program?

### A

🐾 Found it!

Matt led the AWS Launchpad program at Accenture’s Atlanta Innovation Hub from July 2018 to November 2019. Traditional training at Liquid Studio wasn’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The program needed to help them earn certifications and apply those skills to cloud-native projects.

Matt worked with AWS to develop a tailored enablement program. He designed structured learning paths covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. Rather than relying on theory alone, he delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments.

He also established cloud expert mentorship teams so engineers had experienced practitioners to learn from as they developed their skills. Group coaching sessions and knowledge-sharing workshops complemented the structured learning paths. Engineers could practice in labs, learn from mentors, and work through questions together, rather than depend only on traditional training. The mentorship teams also helped retain institutional knowledge and support ongoing learning beyond certification.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, with participants equipped to lead cloud transformation projects.

### B

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs couldn’t keep pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured enablement program that would help engineers earn certifications and apply those skills to cloud-native initiatives.

As Cloud Native Architecture Lead, Matt led AWS Launchpad in collaboration with AWS from July 2018 to November 2019. He designed structured learning paths and certification programs around AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development.

Rather than relying on theory alone, Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. Practical application was part of the learning path, not something deferred until after certification.

He also established cloud expert mentorship teams so engineers could learn AWS best practices from experienced practitioners. Group coaching sessions and knowledge-sharing workshops complemented the structured coursework, giving participants ongoing support and a way to share what they were learning. The program combined certification preparation, practical exercises, and mentor-based training rather than treating certification as a standalone exam.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption and the launch of cloud-native initiatives at Accenture, with mentorship teams and knowledge-sharing workshops supporting continued learning beyond the initial certification effort.
