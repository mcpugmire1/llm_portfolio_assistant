## Visitor: How did Matt build the AWS certification program?

### A

🐾 Here’s how Matt built AWS Launchpad.

At Accenture’s Liquid Studio, traditional training programs weren’t keeping pace with rapidly evolving AWS technologies. Engineers had gaps in cloud competency, and cloud adoption was slowing. The Atlanta Innovation Hub needed a structured program that would help engineers earn certifications and prepare them to lead cloud-native transformation initiatives, rather than rely on training that wasn’t closing those gaps.

As Cloud Native Architecture Lead, Matt led AWS Launchpad from July 2018 to November 2019, working in collaboration with AWS to develop a tailored enablement program. He designed structured learning paths and certification programs covering AWS core services, including Lambda, API Gateway, DynamoDB, Kubernetes, and ECS/Fargate, alongside cloud-native application development. The program connected those learning paths with AWS best practices and the work engineers would encounter on cloud projects.

Instead of relying on theory alone, Matt delivered interactive workshops and hands-on labs that immersed engineers in real-world AWS environments. He established cloud expert mentorship teams so participants could learn from experienced practitioners. He also organized group coaching sessions and knowledge-sharing workshops, bringing engineers together to exchange knowledge and reinforce practical application.

More than 200 professionals earned AWS certifications, including AWS Solutions Architect and DevOps Engineer certifications. The program accelerated cloud adoption across Accenture and established mentorship, coaching, and knowledge-sharing practices to support continued learning beyond certification.
